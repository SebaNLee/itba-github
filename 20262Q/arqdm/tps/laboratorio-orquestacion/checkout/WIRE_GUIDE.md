# Google Wire Dependency Injection Guide - Simplified

## Overview

This microservice uses Google Wire for compile-time dependency injection. Wire generates Go code that wires up your dependencies automatically, eliminating the need for runtime reflection and providing better performance and type safety.

## Simplified Architecture

### Dependency Flow (Direct Concrete Types)
```
Database Connection (gorm.DB)
    ↓
CheckoutDatabaseRepository (*sqlite.CheckoutDatabaseRepository)
    ↓
CheckoutService (*service.CheckoutService)
    ↓
CheckoutHandler (*checkout.Handler)
    ↓
Gin Router
```

## Simplified Wire Configuration

### Wire Configuration File (`cmd/wire.go`)

```go
//go:build wireinject
// +build wireinject

package main

import (
	"github.com/google/wire"
	"gitlab.com/itba-73-40-microservicios/profesores/laboratorio-orquestacion/checkout/internal/database"
	"gitlab.com/itba-73-40-microservicios/profesores/laboratorio-orquestacion/checkout/internal/handler/checkout"
	"gitlab.com/itba-73-40-microservicios/profesores/laboratorio-orquestacion/checkout/internal/repository/sqlite"
	"gitlab.com/itba-73-40-microservicios/profesores/laboratorio-orquestacion/checkout/internal/service"
)

// InitializeApplication wires up all dependencies directly
func InitializeApplication() (*checkout.Handler, error) {
	wire.Build(
		database.GetDatabaseConnection,
		sqlite.NewCheckoutDatabaseRepository,
		service.NewCheckoutService,
		checkout.NewCheckoutHandler,
	)
	return nil, nil
}
```

### Key Simplifications:

- **No ProviderSet**: Direct use of `wire.Build()` with individual providers
- **No wire.Bind()**: Uses concrete types directly, no interface bindings
- **Cleaner imports**: No import aliases needed with better package naming
- **Fewer abstractions**: More direct and easier to understand

## Layer Dependencies (Simplified)

### 1. Database Layer (`internal/database/`)
```go
func GetDatabaseConnection() (*gorm.DB, error) {
	db, err := gorm.Open(sqlite.Open("gorm.db"), &gorm.Config{})
	if err != nil {
		return nil, err
	}
	return db, nil
}
```

### 2. Repository Layer (`internal/repository/sqlite/`)
```go
type CheckoutDatabaseRepository struct {
	db *gorm.DB
}

func NewCheckoutDatabaseRepository(db *gorm.DB) *CheckoutDatabaseRepository {
	// Auto-migrate tables and return repository instance
	if err := db.AutoMigrate(&checkout.Checkout{}); err != nil {
		panic("Failed to migrate database: " + err.Error())
	}
	return &CheckoutDatabaseRepository{db: db}
}

func (r *CheckoutDatabaseRepository) Save(checkout *checkout.Checkout) error {
	result := r.db.Create(checkout)
	return result.Error
}
```

### 3. Service Layer (`internal/service/`)
```go
type CheckoutService struct {
	repository *sqlite.CheckoutDatabaseRepository
}

func NewCheckoutService(repo *sqlite.CheckoutDatabaseRepository) *CheckoutService {
	return &CheckoutService{repository: repo}
}

func (s *CheckoutService) SaveCheckout(checkout *checkout.Checkout) error {
	return s.repository.Save(checkout)
}
```

### 4. Handler Layer (`internal/handler/checkout/`)
```go
type Handler struct {
	svc *service.CheckoutService
}

func NewCheckoutHandler(svc *service.CheckoutService) *Handler {
	return &Handler{svc: svc}
}
```

## Main Application (`cmd/main.go`)

```go
func main() {
	logger := slog.New(slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{
		Level: slog.LevelInfo,
	}))

	// Use Wire to initialize all dependencies
	handler, err := InitializeApplication()
	if err != nil {
		logger.Error("Failed to initialize application", "error", err)
		os.Exit(1)
	}

	// Create router with injected handler
	r := router.ProvideRouter(handler)

	logger.Info("Server starting on port 8080")
	if err := r.Run(":8080"); err != nil {
		logger.Error("Failed to start server", "error", err)
		os.Exit(1)
	}
}
```

## Benefits of Simplified Wire Implementation

### 1. **Compile-Time Safety**
- Dependencies are resolved at compile time
- Type mismatches are caught early
- No runtime surprises

### 2. **Performance**
- No reflection overhead
- Generated code is as fast as hand-written code
- Minimal memory allocation

### 3. **Simplicity**
- Direct concrete type usage
- No complex interface bindings
- Easier to understand and maintain
- No import aliases needed

### 4. **Testability**
Each layer can be tested independently by providing mock implementations or test doubles:

```go
// Example: Testing service layer with a test repository
func TestCheckoutService(t *testing.T) {
	// Create test database

	testRepo := sqlite.NewCheckoutDatabaseRepository(db)
	
	service := service.NewCheckoutService(testRepo)
	// ... test logic
}
```

## Working with Simplified Wire

### Adding New Dependencies

1. **Create Provider Function**:
```go
func NewMyService(dependency *SomeConcreteType) *MyService {
	return &MyService{dep: dependency}
}
```

2. **Add to wire.Build**:
```go
func InitializeApplication() (*checkout.Handler, error) {
	wire.Build(
		database.GetDatabaseConnection,
		sqlite.NewCheckoutDatabaseRepository,
		service.NewCheckoutService,
		NewMyService,           // Add new provider here
		checkout.NewCheckoutHandler,
	)
	return nil, nil
}
```

3. **Regenerate**:
```bash
wire gen ./cmd
```

### No Interface Binding Needed

Since we use concrete types directly:
- No `wire.Bind()` calls needed
- No complex interface management
- Direct dependency injection

## Error Handling

Wire will fail with helpful messages if:
- Missing providers for required dependencies
- Circular dependencies exist
- Interface bindings are incorrect
- Unused providers are included

## Best Practices for Simplified Wire

1. **Keep providers simple** - One responsibility per provider
2. **Use concrete types when possible** - Simpler than interfaces for many use cases
3. **Handle errors properly** - Database connections, file operations, etc.
4. **Organize packages logically** - Avoid naming conflicts
5. **Test each layer** - Use test databases and concrete implementations

This simplified Wire configuration:

The resulting code is easier to understand, modify, and test while still providing the performance and safety benefits of Wire dependency injection.
